# MR-TADF

两个 MR-TADF 计算研究方向的课题说明与阶段日志，供研究指导和进展评估。

**完整报告见 [实验日志.md](实验日志.md)。** 日志中的状态均附核对时间，并区分文献观察、本项目结果和待实施方案。

研究方向包括：

- 羰基 MR-TADF 分子在甲苯中的光降解，比较溶剂接近、HAT 势垒和抽氢后反应分支。
- OMeBOBO／EnBOBO 主客体掺杂膜的低能发射，检验发光体聚集、敏化剂参与和局部环境的贡献。

日志包含实验条件与出处、结构可靠性、量化方法、逐项作业状态、首项发射对照、频率计算进度、MD／QM/MM 方案、现有限制及下一阶段验收标准。

计算结果按当前记录的模型和验收阶段解释。OMeBOBO 的结构假设在报告中保留标记。
